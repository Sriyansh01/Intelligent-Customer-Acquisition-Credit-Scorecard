📌 Project Title
Intelligent Customer Acquisition Credit Scorecard

📖 Project Overview
This project builds a machine learning-based credit scorecard system to predict customer creditworthiness for intelligent acquisition targeting.
The full dataset (~2GB) is hosted externally due to GitHub size limitations.

📂 Project Structure
data/          → Contains small sample dataset for testing
notebooks/     → Step-by-step development notebooks
src/           → Production-ready Python scripts
models/        → Saved trained models
requirements.txt → Project dependencies


📊 Dataset
Due to GitHub file size restrictions, the full dataset is hosted externally:

🔗 Dataset Link: https://www.kaggle.com/competitions/home-credit-default-risk/data

A small sample dataset is included inside data/ for demonstration purposes.
